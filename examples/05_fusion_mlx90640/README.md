# 05 MLX90640 双光融合

```sh
pio run -e 05_fusion_mlx90640
```

先完成前两项成像实验，再烧录本章。让一个可见的温热目标在画面中移动，用串口命令调整两幅画面的重合位置。

按热图的画幅裁切可见光，逐点对可见光采样，并用 RGB565 混色得到叠加图。

[实验入口](main.cpp) · [fusion.hpp](../../include/fusion.hpp)

## 串口调节

以 115200 波特率打开串口，选择换行发送。设置保存在本次运行中，重启后恢复默认。

| 命令 | 作用 |
| --- | --- |
| `alpha 128` | 可见光混色系数。0 显示纯热图，数值越大重叠区域的可见光权重越高，255 时重叠区域为纯可见光。 |
| `align 5 -3 1.1 0` | 设置可见光的 X/Y 像素偏移、缩放倍率、顺时针旋转角度。X 向右、Y 向下，缩放范围为 0.25–4。 |
| `align 0 0 1 0` | 恢复居中、原始倍率和零转角。 |
| `bootloader` | 重启进入 RP2040 的 UF2 烧录模式。 |

配准建议用能同时辨认轮廓和温差的物体，先平移中心，再调倍率和角度。调整过程中可用 `alpha 128` 同时观察两层。
